FOLDER FOTO CAPSTER
====================
Foto profil capster (capster-susi.jpg, capster-nia.jpg, capster-rani.jpg,
capster-dinda.jpg, capster-wulan.jpg) di folder ini adalah foto hasil AI
generator (bukan foto orang sungguhan), digunakan sebagai placeholder
visual yang menarik untuk demo website.

Kalau nanti sudah punya foto asli capster (dengan izin mereka), tinggal
ganti file dengan nama yang sama, format persegi (disarankan 480x480px
atau lebih, rasio 1:1) agar otomatis pas di bingkai foto profil bulat.

Pengaturan foto ada di script.js pada CONFIG.capsters, contoh:
  { id: 'nia', name: 'Nia', ..., photo: 'img/capster-nia.jpg' }

Kosongkan field "photo" (photo: '') untuk kembali ke avatar inisial
elegan sebagai fallback.
